# AEML, NTUST｜RC 設計工具：2D 構架分析

本儲存庫僅存放「2D 構架分析」工具之發布網頁（`index.html`），透過 GitHub Pages 提供線上使用。
所有計算在使用者瀏覽器內完成，不上傳任何資料。

- 依據：建築物混凝土結構設計規範（112 年版）與 ACI CODE-318-25
- 計算結果可用「複製傳送碼」送到 concrete.tw 上之柱、梁設計工具（按「貼上傳送碼」匯入）
